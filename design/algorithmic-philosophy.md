# 泊流 · The Berth Current

> 为「挪车二维码」重设计而生成的算法哲学。
> 一条马路是一条河，一次临停是河里的一块静水，一张挪车贴纸是让静水重新汇入河流的钥匙。

## 哲学

**泊流**（The Berth Current）是一门关于「暂停与恢复」的计算美学。城市车流在数学上是一条恒定的流场——每辆车都是一个沿矢量前进的粒子；而「临时停靠」是流场里一块短暂的死水：粒子停下来了，但它身后的车流仍在涌动。挪车二维码的存在意义，就是把这块死水以最短的时间重新溶解回河流。因此这门美学的一切表达都围绕一个母题：**秩序网格中的湍流，以及网格被一个信号唤醒的瞬间**。

它的第一层语言是**模块网格**。二维码是人类的印章：一个把网址压成黑白方格的秩序系统。在泊流的世界里，画布永远从一张网格开始——每个格子都是一个潜在的模块，可以被点亮、被流场冲刷、被脉冲唤醒。格子不是像素，它们有呼吸：以分层噪声决定明暗，以缓慢的相位漂移决定生灭，远看是纹理，近看是一部可以解码的经纬书。网格的三个角上，二维码的「定位图形」化作三座灯塔——它们是整个系统里唯一恒定不动的存在，是湍流中Anchor，是扫码器（也是观者）确认「我在正确的秩序里」的原点。

它的第二层语言是**车道流线**。画布上有几条贯穿的虚线——那是马路上车道线的抽象。粒子沿这些车道滑行，像晚高峰的车灯拖出光轨；当粒子经过模块网格时，会短暂点亮途经的格子，于是「车流」在「二维码」身上留下转瞬即逝的曝光。流线的密度、速度、弯曲度全部由种子化的噪声场驱动：同一份哲学，每一颗种子都是这座城市另一天的交通。

它的第三层语言是**连接脉冲**。整个系统定期从某一颗定位灯塔发出一圈涟漪——那是「一键拨号」被按下的瞬间：一个信号从贴纸出发，穿过网格，把车主和陌生人连在同一条波前上。涟漪经过之处，格子被依次点亮又缓缓熄灭，像水面上一圈扩散又平复的波。这是画面里唯一的叙事性事件，其余一切都为这一刻的醒目而让路：背景克制、网格低语、流线退后，只有脉冲是主角。

配色遵循「清雅蓝绿」：以太蓝（azure）为秩序之色，以青碧（teal）为生命之色，大量留白与极浅的底色让所有墨色都站得稳。所有参数——网格密度、流场尺度、脉冲频率、灯塔相位、色相配比——都必须经过反复调校，直到任意一颗种子都能长出一幅**可以直接印在名片上的构图**。这门哲学的最终算法应当像一位顶级生成艺术家耗时数百小时打磨出的作品：每一处斜率都有出处，每一处留白都经过计算，克制到几乎看不见设计，但处处都是设计。

## 静态化约定（供站点 UI 落地）

站点 CSP 为 `default-src 'none'`，禁止外部脚本与内联脚本/样式，因此泊流在真实页面中以**冻结的静态切片**存在：

1. **点阵网格**：低透明度的圆角方格阵列（`currentColor` + opacity 分层，自动适配深浅色）；
2. **三座灯塔**：三个定位图形式的小方块组，作为品牌记号出现在顶栏与登录页；
3. **车道虚线**：横向虚线段，用于分隔与装饰性收边；
4. **涟漪弧线**：拨号按钮周围的一圈同心圆弧，只在扫码页 hero 区出现，纯装饰。

全部以内联 SVG（`aria-hidden="true"`、`focusable="false"`）与 CSS 渐变实现，不引入任何外部资源。
